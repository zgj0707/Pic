# Pic UI/UX 重构执行计划

> 产品定位：拍摄前参考样片收集与整理工具
> 当前修订目标：Pic 3.4.1
> 修订日期：2026-08-23

## 一、产品边界

Pic 服务于摄影师在拍摄前从互联网或本地收集样片、筛选参考、整理灵感板，并把最终选中的原始样片复制到桌面文件夹。

核心闭环只有一条：

收集样片 → 快速筛选 → 选择参考 → 保存到桌面文件夹

明确不做：

- 不作为模特或客户成片交付工具。
- 不生成 PDF、联系表或交付画册。
- 不把 Shot List、方案制作或现场执行管理放进主流程。
- 不修改参考图原文件。
- 不一次性迁移框架，也不同时重写数据库与全部 UI。

已有 Shot List、方案导出相关数据库表保留，仅用于历史数据兼容；界面不再暴露这些功能，不删除用户已有记录。

## 二、执行规则

- 一次只完成一个阶段。
- 保留开始阶段前已有的未提交修改，不使用 reset 或 checkout 覆盖用户工作。
- 每阶段测试通过后独立提交。
- portable 验证前必须递增版本并重新打包。
- 每阶段都以真实用户路径验收，不以“代码存在”代替功能可用。

## 三、四阶段计划

### 阶段 1：产品语义与项目入口

目标：将软件统一定义为拍摄前样片工具。

- 项目承载拍摄主题、描述和日期。
- 文案统一使用“参考样片、收集、筛选、灵感板”。
- 保留现有数据库和导入能力。
- 清除客户交付语义。

完成标准：用户进入软件后能理解这是拍摄前找样片和整理参考的工作台。

### 阶段 2：互联网与本地样片收集

目标：让不同来源的参考图进入同一项目。

- 支持本地文件、文件夹和内置素材浏览器。
- 保存来源类型、来源网址和来源备注。
- 支持按网页样片、本地样片、收藏、评级和标签筛选。
- 缺失来源信息不阻断导入。

完成标准：用户可以收集并追溯互联网和本地样片。

### 阶段 3：筛选、对比与灵感板

目标：高效得到最终参考集合。

- 支持快速初筛、评级、收藏和标签。
- 支持把参考样片加入灵感板并调整顺序。
- 支持 2–4 张参考图并排对比。
- 保持分页、虚拟滚动、键盘操作和 reduced-motion。

完成标准：用户可从大量样片中整理出一组明确的拍摄参考。

### 阶段 4：桌面保存、界面收敛与 portable

目标：用一个清楚的结果动作结束流程。

- 顶部只保留“保存到桌面”作为结果操作。
- 将所选原始样片复制到桌面的“项目名-日期”文件夹。
- 文件重名时自动添加序号，绝不覆盖已有文件。
- 原图缺失时准确报告成功与失败数量。
- 主界面移除 PDF、Shot List 和方案入口。
- 阶段栏收敛为“收集样片、快速筛选、灵感板”三步。
- 默认筛选项收敛为“全部、网页样片、本地样片、收藏”，评级与标签使用下拉筛选。
- 版本递增到 3.4.1 后重新生成 portable 并执行功能验收。

完成标准：用户选择样片后，一次点击即可在桌面得到文件夹；界面没有相互竞争的导出入口；测试、构建和 portable 启动验证通过。

## 四、验收清单

1. 新建或选择项目。
2. 从本地或互联网导入样片。
3. 使用来源、收藏、评级或标签筛选。
4. 多选样片，确认“保存到桌面”按钮启用。
5. 点击保存，确认桌面生成“项目名-日期”文件夹。
6. 确认文件内容与原图一致，原图未被移动或修改。
7. 使用两个同名文件重复验收，确认自动生成不重名副本且不覆盖。
8. 使用一个缺失原图验收，确认成功数和失败数准确。
9. 确认主界面没有 PDF、Shot List 或方案入口。
10. 执行测试、类型检查、lint、构建和 3.4.1 portable 启动验证。
