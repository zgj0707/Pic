针对你的三点需求

① 五景别分镜

  • 分镜板固定五条轨道：远景 / 中景 / 近景 / 特写 / 空镜，每条独立编号、独立配色。
  • 景别是拍摄现场的调度语言，比自由分组更贴合人像拍摄；空镜轨道常用来垫转场与氛围镜头。
  • 导出 PDF 按远景 → 空镜顺序成稿，与现场拍摄顺序一致。

② 多项目分区

  • 左侧项目分区常驻：每个项目独立封面、独立统计（样片 / 镜头 / 已拍进度），点击即切换整块工作区，数据完全隔离。
  • 新建项目一键创建空板。

③ 跨项目拖拽复制

  • 把分镜卡片拖到左侧任一项目上松开 → 复制一份到该项目的同一景别，原卡片保留，副本带「副本」标签可溯源。
  • 同理，收集箱拍板、景别间移动都是拖拽 / 一键操作，全程无对话框。
