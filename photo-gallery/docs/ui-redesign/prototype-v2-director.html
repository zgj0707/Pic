为什么这样设计

从工作本质推导

  • 两个心智时刻：收集时"先扔进来别想"，拍板时"只管顺序"。所以界面只有两个主动作空间 —— 收集箱 → 分镜板，中间不再有第三种状态。
  • 拍摄清单的本质是顺序，不是文件夹。所以主界面是横向分镜轨道（场景=列，镜头=卡），顺序即视觉本身，导出 PDF 与屏幕顺序 1:1。
  • 分组即场景：用颜色 + 名字命名拍摄段落（开场/产品/人物/收尾），比树形列表更接近拍摄现场的语言。

易用性决策

  • Icon Rail 替代大侧栏：空间只有 5 个，68px 图标栏足够，把 90% 宽度还给内容。
  • 收集箱拍板：hover 出场景按钮 + 数字快捷键 1/2/3 拍板、X 丢弃，百张样片几分钟能分完。
  • 简报常驻一行：交付目标与进度钉在板顶，编辑时才展开，不再是一大块表单。
  • Ctrl+K 命令条：搜索样片、跳空间、执行动作统一入口。

视觉 · 画廊纸感（与旧版彻底区分）

  • 为什么浅色：与导出的印刷 PDF 同一质感体系，屏幕与纸面连贯；样片卡自带白底阴影，浮在纸面上。
  • 陶土橘：只用于动作与品牌，场景/状态用四色场景板，避免金色既是品牌又是选中态的语义混用。
  • 动效克制：130ms 反馈 / 220ms 位移；深色模式可做第二主题（纸感反转），不在本版展开。
